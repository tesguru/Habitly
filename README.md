# Habitly

A native iOS habit tracker built with SwiftUI.

Habitly helps you build better habits by tracking daily completions, streaks, and progress — all stored locally on your device.

## Features

- **Onboarding flow** — first-time user introduction
- **Create habits** — add habits with a name and icon
- **Complete daily** — tap to mark a habit done for today
- **Streaks** — see how many days in a row you've completed a habit
- **Edit habits** — change the name anytime from the details screen
- **Delete habits** — swipe to remove
- **History** — see every day a habit was completed
- **Insights** — totals, best streak, completions today
- **Profile** — clear all data
- **Persistence** — habits survive app restarts

## Tech

- **SwiftUI**
- **Swift**
- **MVVM architecture**
- **@Observable** for reactive state
- **@AppStorage / UserDefaults + Codable** for local persistence
